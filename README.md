# 🩸 RiasOS: The Crimson-Kerneled Operating System 

Rias is my journey into operating systems, computer architecture, and low-level systems programming. The primary goal is to learn how modern kernels work by building one from scratch.

## Roadmap
- [x] Bootloader & kernel entry
- [ ] VGA text output & serial logging
- [ ] Interrupts & exception handling
- [ ] Physical & virtual memory management
- [ ] Heap allocator
- [ ] Keyboard input
- [ ] Cooperative multitasking
- [ ] Basic shell
- [ ] Filesystem support
- [ ] User-space programs (stretch goal)
